### EduBuddy (AI Powered Learning and Career Assistant)

EduBuddy is an AI-powered learning platform designed to make learning smarter and more accessible. It helps students understand concepts, get learning assistance, and improve their academic productivity through intelligent, technology-driven features.

### Trustify (Fake Product Detection Using Machine Learning & Computer Vision)

Trustify is an ML-powered product verification system that identifies potentially counterfeit products by analyzing product details, seller ratings, pricing patterns, and suspicious indicators. It combines QR code detection, URL scanning, and machine learning to help users make safer online shopping decisions.

**Tech Stack:**  Python, Scikit-learn, Random Forest, OpenCV, Pandas, NumPy, Streamlit, Playwright
